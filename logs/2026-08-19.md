### 电脑版（新增同步服务）
- 新增 app/core/sync_server.py：局域网 HTTP 同步服务（默认端口 47520）
  - GET /api/ping：检测服务
  - GET /api/plan：手机拉取电脑数据
  - POST /api/plan：手机推送数据到电脑（覆盖前自动备份 plan.bak.json）
- 主窗口底部新增「🔄 同步」按钮 → 同步弹窗：显示服务状态、电脑 IP 地址、启动/停止开关
- 同步服务随程序启动自动运行（可在同步弹窗里关闭，选择记住）
- 手机推送数据后电脑自动刷新界面与提醒
- 新增 tests/test_sync.py（4 个用例），全部桌面测试 58 个通过
- 真实联调验证：ping / 拉取 / 推送 / 再拉取全部正常
- 重新打包桌面版 exe（57.8MB，含同步功能），旧版备份为 dist\每日计划_old_v1.0.exe

### 手机版（新增同步页）
- 新增 lib/sync_page.dart：设置 → 数据 → 电脑同步

  - 「拉取：电脑 → 手机」和「推送：手机 → 电脑」两个按钮
