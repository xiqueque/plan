# 每日计划 —— 需求规格说明书

> 版本：v1.0（已确认）
> 确认日期：2026-08-07
> 状态：已确认，进入开发阶段

## 1. 软件概述

- 软件名称：每日计划
- 运行平台：Windows 电脑
- 使用方式：双击打开，显示在桌面上
- 数据保存：全部保存在本地电脑，不需要联网
- 界面语言：中文
- 界面风格：简洁、直观、背景透明，默认淡蓝色

## 2. 核心功能

### 2.1 每日计划管理

- 每天一个计划列表，可以新增、编辑、删除计划项
- 每条计划可以选填时间段（如 9:00-10:00），也可以只写文字
- 计划项可以勾选完成，完成的条目有标记（划线或变色）
- 勾选完成时播放一个可爱、短暂的内置音效（程序自带，无需联网）
- 勾选任务完成时会弹出确认框「你确定完成任务了吗( •̀ ω •́ )✧」，提供「确定(●'◡'●)」和「我再想想¯\_(ツ)_/¯」两个选项（微软雅黑字体）
- 确认完成后弹出庆祝提示「终于完成任务了耶o(*≧▽≦)ツ┏━┓！！！」，该文案可在设置中修改
- 默认音效使用本地音频 C:\Users\Junhong\Music\8月7日.mp3 的裁剪版（去掉开头约 0.76 秒静音，让「啵」音立即响起；可在设置中更换，支持 wav / mp3，也可恢复默认）
- 音效音量可在设置中调节（0-100%），默认 12%；勾选完成与到点提醒共用此音效设置
- 任务从未完成切换为完成（或取消完成）时，文字有颜色渐变 + 轻微弹跳的小动画，过渡不生硬

### 2.2 置顶

- 可以把任意一条计划置顶，固定在列表最上方
- 多条置顶时按置顶先后排列，置顶的始终排在未置顶的前面

### 2.3 搜索

- 顶部有搜索框，输入关键词后，计划列表即时过滤，只显示匹配的内容

### 2.4 日期与翻看

- 窗口左上角显示当前查看的日期
- 可以翻看前一天 / 后一天，也可以一键回到今天
- 数据自动清理：超过设定天数（默认 15 天，天数可手动调整）的计划自动删除
- 标记为「每天提醒」的计划不会被自动清理，除非手动删除
- 「每天提醒」的计划每天自动出现在当天的计划列表里，当天打勾完成后，第二天自动恢复为未完成

### 2.5 图片

- 独立图片区：可以添加多张图片（如课程表），可以查看和删除
- 每条计划可以附带图片（选填）
- 图片以缩略图显示在窗口中，点击可查看大图，右上角 × 可删除
- 图片会复制保存到软件数据目录中，不依赖原文件位置
- 点击图片改用电脑默认程序打开（设置中可改为自定义程序），不再使用软件内小窗口
- 图片区平时折叠为一行（显示张数），点击展开查看
- 图片删除改为右键菜单操作（打开 / 重命名 / 删除）
- 支持在软件内右键重命名图片（显示名）
- 图片区可以右键把图片「标记为每日图片」：该图片每天都会出现在图片区，缩略图左上角显示金色星标 ★，可随时取消标记
- 每天提醒任务附带的图片会跟随任务每天出现在图片区；这类图片（来源为任务）不可在图片区删除
- 图片区只剩一张时也可以删除

### 2.6 提醒

- 每条计划可以设置提醒时间，提醒模式三种：
  - 每天提醒：每天都到点提醒
  - 仅当日提醒：只在计划所属的当天提醒
  - 不提醒
- 提醒时间通过弹出式时间选择器快速选择（小时 + 分钟两列，双击或确定确认），无需手动打字
- 每条提醒可以勾选周一至周日（默认全选，提供「全选」和「工作日（周一~五）」快捷按钮）；不在勾选范围内的星期不会提醒
- 到点后：从屏幕右下角弹出一个小提醒弹窗，带弹出动画（从右下角滑出/弹出的效果）
- 提醒音效：默认内置一个短暂、可爱、有趣的音效；全局一个音效，可以在设置里替换成自己本地的音频文件（如 mp3 / wav）
- 点击提醒弹窗可以查看详情或关闭它
- 软件未运行时（如电脑关机、软件没开）不提醒，也不补发
- 提醒只在软件运行时生效；同一任务同一天同一时间只提醒一次，不会重复弹窗

### 2.7 开机自启动

- 设置里可以开关「开机自动启动」
- 开启后电脑开机自动运行本软件，方便到点提醒
- 开机自启动通过系统启动项实现，在「设置」中勾选即可

### 2.8 计划截图导出

- 一键生成当天计划的截图（PNG 图片），保存到本地任意位置
- 截图是干净的计划卡片（不含软件按钮），方便保存后发到手机查看
- 截图标题为「每日计划 · 日期」，已完成的任务显示为灰色划线

## 3. 界面要求

- 简洁直观，中文界面
- 背景透明，只显示内容区域
- 主窗口为透明圆角无边框样式，可按住空白处拖动，右下角可调整大小
- 提供 8 套图片配色主题（取自 C:\Users\Junhong\Pictures\peise 的 8 张样例图），在设置中一键切换；默认淡蓝主题始终保留
- 每套图片主题配有一个四字名称（如碧海晴空、青翠山林等），按图片配色自动分配
- 点击最小化按钮默认回到桌面右上角，以半透明迷你窗口显示今日计划（大小、不透明度可调，双击或「展开」恢复完整窗口）
- 点击关闭按钮默认收进系统托盘；最小化与关闭的行为都可在设置中更改（托盘 / 直接退出）
- 窗口左上角显示日期
- 日期显示参考 C:\Users\Junhong\Pictures\Screenshots 最新截图的配色，以生动渐变样式展示（无截图时保持主题样式）
- 提供「月计划」查看：按月分组显示当天计划与每天任务，可翻看前后月份；当月无计划时显示「本月暂无计划」
- 窗口为横屏布局（默认约 820 x 540），大小可自由调整，最小可缩到约 480 x 340
- 点击日期弹出日历，可快速跳转到任意日期
- 每条任务的字体颜色可以自定义（黑 / 红 / 橙 / 蓝 / 绿 / 紫），用于区分紧急程度
- 任务文字加粗显示，更醒目
- 桌面上提供「每日计划」快捷方式图标，双击即可打开
- 边框、按钮等主要颜色可以自定义，默认淡蓝色
- 窗口可以拖动位置，可以调整大小
- 最小化时收进系统托盘继续运行（方便后台提醒）
- 提供「窗口总在最前」开关，默认关闭
- 最小化或关闭时收进系统托盘继续运行，托盘菜单可显示 / 退出
- 迷你窗口不显示在任务栏中，且只读展示任务（不可在迷你窗口勾选）

## 4. 技术方案（简述）

- 本地单机程序，不需要联网
- 数据保存在本地文件中
- 打包成 .exe，双击即可运行
- 开机自启动通过系统「启动」功能实现

## 5. 需求确认记录

1. 「置顶」= 计划置顶（某一条计划固定在列表顶部），不是窗口置顶
2. 计划形式 = 清单为主，每条计划可选填时间段
3. 图片 = 独立图片区 + 每条计划可附带图片（两者都要）
4. 提醒 = 三种模式可选；软件未运行时不提醒；提供开机自启动开关
5. 日期 = 可翻看前后日期；超过 15 天自动清除（天数可调）
6. 「每天提醒」任务 = 每天自动出现在当天列表，打勾完成后第二天恢复未完成
7. 提醒形式 = 屏幕右下角小弹窗 + 弹出动画 + 短暂可爱有趣的音效（可换本地音频）
8. 提醒音效 = 全局一个，设置里替换一次全部生效
9. 「窗口总在最前」= 提供开关，默认关闭
10. 软件名称 = 每日计划
