# 开发步骤（分阶段执行）

> 版本：v0.1
> 原则：每个阶段完成 → 自测 → 更新开发日志 → git 提交 → 交付用户试用。
> 不跨阶段一口气做太多，保证项目稳定推进。

## Phase 0：项目基础（已完成）

- 内容：需求确认、建立 docs / logs 文档体系、规划本文件
- 验收标准：README 可读、需求已确认、文档齐全

## Phase 1：最小可用版本（MVP）【已开发完成，待用户试用】

- 内容：
  - 主窗口：日期显示（左上角）、前一天 / 后一天 / 今天切换
  - 计划：新增、编辑、删除、勾选完成、置顶、搜索
  - 本地 JSON 保存；「每天提醒」任务每天自动出现，完成状态按天记录
  - 自动清理：超过默认 15 天（可调）的数据自动删除
- 完成标准：每日计划可正常使用，重启软件数据不丢失
- 验证方式：实际运行日常使用，交付用户试用
- 当前状态：已完成开发（日期切换、计划增删改、勾选完成、置顶、搜索、每天重复任务、自动清理、设置清理天数），等待用户试用反馈

## Phase 2：提醒功能【已开发完成，待用户试用】

- 内容：
  - 每条计划三种提醒模式（每天 / 仅当日 / 不提醒）与时间设置
  - 屏幕右下角弹窗 + 滑入动画 + 默认可爱音效
  - 音效可在设置中替换为本地音频
  - 软件未运行不提醒；开机自启动开关
- 完成标准：到点正常弹窗并播放声音，音效可替换
- 验证方式：设置 1 分钟后提醒实测
- 当前状态：已完成（三种提醒模式、右下角弹窗滑入动画、共用音效与音量、开机自启动开关、防重复提醒）

## Phase 3：图片功能【已开发完成，待用户试用】

- 内容：
  - 独立图片区：添加、查看、删除图片
  - 每条计划可附带图片
- 完成标准：课程表等图片正常显示与删除
- 验证方式：导入真实图片测试
- 当前状态：已完成（独立图片区：缩略图、点击查看大图、删除；每条计划可附图；图片随数据自动清理）

## Phase 4：界面完善

- 内容：
  - 透明背景正式化
  - 颜色自定义：预设色板 + 取色器，默认淡蓝，可恢复默认
  - 系统托盘、窗口总在最前开关
- 完成标准：不同壁纸下观感正常，颜色可自由调整
- 验证方式：多种壁纸下测试

## Phase 5：测试与发布

- 内容：
  - 全面自测 + 用户试用反馈
  - 打包成 exe，编写使用说明（备份数据、换音效等）
  - 交付
- 完成标准：新电脑双击即可运行

## 日常规则

- 每个开发日开始：查看 logs 最新日志与待办事项
- 每个开发日结束：更新当日日志（完成事项 / 待办事项）
- 每个阶段结束：git 提交，提交信息注明阶段
