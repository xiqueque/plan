# 界面设计规范

> 版本：v0.1
> 说明：界面布局、配色、交互的统一标准，编写界面时遵循。

## 1. 设计原则

- 简洁、直观，日常查看不刺眼
- 背景透明，只显示内容区域
- 默认淡蓝色调，所有主要颜色可自定义

## 2. 主窗口布局

- 默认尺寸：约 820 x 540（横屏），可拖拽调整大小，最小 480 x 340
- 无边框透明圆角窗口：按住空白处可拖动位置，右下角拖拽柄可调整大小，左上角提供最小化（收托盘）与关闭（收托盘）按钮
- 顶部：日期（左上角）+ 设置按钮
  - 点击日期会弹出日历，可快速跳转到任意日期（也保留前一天 / 今天 / 后一天按钮）
- 中部：搜索框；计划列表
  - 排序规则：置顶的计划在前；其余按时间段排序，无时间的按创建顺序
- 列表项：完成勾选 | 文字 + 时间段 | 置顶 / 编辑 / 删除（大号按钮，15px 文字）
- 置顶的计划在任务文字右侧显示柔和淡蓝色自绘图钉小图标，一眼可辨且不刺眼
  - 完成勾选框为大号自绘圆角样式（36px），更醒目
  - 其他复选框（提醒日、时间段、开机自启等）勾选框统一放大为 22px，文字 15px
- 底部：添加计划、截图、设置按钮；顶部分别提供今天按钮、前一天 / 后一天切换
- 独立图片区：课程表等图片缩略图，点击放大，可删除
- 每条计划可附带图片（选填）

### 图片区与缩略图

- 搜索框下方为独立图片区：平时折叠为一行（「图片 ▸」+ 张数），点击展开；缩略图横向排列，可横向滚动
- 点击缩略图用电脑默认程序打开图片（设置中可选自定义程序，如画图）
- 右键缩略图弹出菜单：打开 / 重命名 / 标记为每日图片（或取消）/ 删除
- 标记为每日图片后，星标直接画在该缩略图左上角（金色 ★），不会出现第二张重复图片；右键可随时取消标记
- 每天提醒任务附带的图片自动每天出现在图片区（来源为任务，仅可打开/重命名，不可删除）
- 缩略图下方显示自定义名称（软件内右键重命名），过长自动省略
- 图片「重命名」是赋予新显示名（不改动原图片文件），支持中文、英文与 ASCII 字符；弹窗中有明确说明
- 设置窗口中的提示 / 注意文字使用淡灰色小字（12px），与主要选项区分开
- 图片复制到 app/data/images/ 保存，删除后文件一并清理；过期日期的图片随自动清理删除
- 添加 / 编辑计划时可附带图片（支持 png / jpg / jpeg / bmp / gif / webp），任务行显示「图片 N」标记

## 3. 配色（默认淡蓝）

- 主色：#A8D8EA（淡蓝）
- 边框：#7FB8D4
- 按钮：#ADD8E6，悬停时加深
- 文字：#1F3A4D
- 完成态：#9AA5AC 划线显示
- 背景：透明（默认）
- 自定义范围：主色、边框、按钮、文字等主要颜色
  - 提供预设色板 + 自定义取色；可一键恢复默认淡蓝

### 任务字体颜色

- 每条任务可以选择字体颜色，按紧急程度区分：
  - 黑色（默认）、红色（紧急）、橙色（重要）、蓝色（常规）、绿色（轻松）、紫色（备忘）
- 已完成的任务统一显示为灰色并划线

## 4. 字体

- 主字体：幼圆（圆润、可爱、饱满），后备微软雅黑
- 字号：日期标题 20px，任务正文 18px（字重 500），时间 13px，按钮 14px
- 任务文字加粗（字重 600）

### 日期生动化

- 点击日期弹出日历，日历下方实时显示选中当天的计划（含时间段、完成状态）；没有计划时显示「这一天没有计划」
- 日历弹窗为大气圆角卡片样式：无边框圆角背景、圆角日历与任务卡片、更大的尺寸与留白、可按住空白处拖动
- 日历为自绘大方块：18px 大号日期数字、圆角矩形方块、方块间留 8px 间距；今天与选中日高亮、周末浅暖色
- 方块内直接显示当天任务名（最多 2 条，超出显示「… 还有 N 条」）；单击方块弹出当天计划详情，双击方块直接跳转
- 日历弹窗提供「截图」按钮：生成干净月度计划卡片（含月份标题、任务名），默认保存为「月度计划_YYYY-MM.png」

### 月度计划

- 底部「月计划」按钮打开月度视图：每天任务单独分组、其他计划按日期分组，可翻看上一月 / 下一月 / 回到本月
- 当月没有任何计划时显示「本月暂无计划」

## 6.2 计划截图卡片

- 点击「截图」生成当天的干净计划卡片（无软件按钮）
- 卡片样式：浅蓝背景 + 白色圆角任务行，与主界面一致
- 标题「每日计划 · 日期」；任务保留字体颜色；已完成任务灰色划线
- 文件名默认「每日计划_YYYY-MM-DD.png」

## 7. 桌面快捷方式

- 桌面上提供「每日计划」快捷方式图标（淡蓝色日历 + 对勾）
- 双击图标即可打开软件；图标可在 scripts/create_shortcut.ps1 中重新生成

## 8. 窗口置顶

- 窗口默认不置顶（普通窗口）；「总在最前」开关在后续版本提供，默认保持关闭

## 9. 主题与托盘

- 默认淡蓝主题；另提供 8 套图片配色主题（取自 C:\Users\Junhong\Pictures\peise 的 8 张样例图，程序自动提取主色）
- 8 套主题按配色分配四字名称（碧海晴空、青翠山林、暖阳橙光、桃粉春色、紫霞暮色、金秋麦浪、冰川银雪、莓果甜心）
- 主题在「设置 → 主题」中一键切换，界面背景、边框、按钮、文字随之变化
- 系统托盘：最小化 / 关闭收进托盘，提醒继续运行；托盘右键可显示或退出

### 迷你窗口

- 点击「—」默认进入桌面右上角半透明迷你窗口（默认约 320x240，最小 260x180，可拖动、右下角调整大小）
- 日期重点突出：月日 30px 加粗高亮，年份 + 星期 15px 加粗
- 任务双列显示，任务多时滚动条滚轮滑动
- 每个任务带勾选框，可在迷你窗口直接勾选完成（完成后灰色划线，播放音效）
- 任务有时间段时，在任务文字下方用淡灰色小字显示（如 09:00 – 10:00）
- 透明度只作用于背景：文字、数字与「展开」按钮始终清晰不透明（默认 80%）
- 迷你窗口不显示在任务栏（Qt.Tool 窗口），只读展示任务，无勾选框
- 迷你窗口固定图标默认使用 D:\Downloads 最新图片（无图时回退自绘图钉），固定时高亮

### 按键提示音

- 每次点击按钮都会播放提示音（默认 C:\Users\Junhong\Music\8月8日.mp3，音量约 50%）
- 提示音使用 Qt 多媒体播放（mp3 可靠播放）

### 跨午夜时间段

- 结束时间早于开始时间时视为跨午夜，列表显示「开始 – 次日结束」，其中「次日」为淡灰色

### 窗口弹出动画

- 启动与进入迷你窗口时：淡入（0.1 → 目标不透明度）+ 弹性回弹（OutBack，约 280ms）

### 批量编辑

- 底部「批量编辑」进入多选模式，每行左侧出现选择框
- 可批量修改字体颜色 / 时间段 / 提醒（含清除）、批量置顶 / 取消置顶、批量删除（删除后清理孤儿图片）

### 音乐播放器

- 底部「音乐」按钮打开播放器窗口：播放列表 + 播放/暂停/停止/上一首/下一首 + 添加音频 + 移除选中 + 音量滑杆
- 默认曲目为程序内置音乐（app/assets/music 下最新音频），随 exe / 压缩包分发
- 播放器关闭后音乐继续播放（可点停止）；音量记忆在设置中
- 音乐播放器为俏皮暖色样式：曲名 20px 加粗、列表 17px、带可点击/拖动进度条与时间显示
- 播放模式：顺序播放 / 单曲循环 / 随机播放（已取消优先级）
- 随机模式下播放键显示「🔀 随机播放」，按一下从随机一首开始，自动切歌也是随机
- 双击列表曲目直接播放；拖拽曲目可调整播放顺序（自动保存）
- 添加新音乐时内置音乐自动保留，不会丢失
- 单曲循环采用「快播完时自动回到开头重播」的轮询检测（更可靠，不依赖 EndOfMedia 事件）；顺序播放播完列表停止
- 播放 / 暂停合并为一个按钮：▶ 播放 ↔ ⏸ 暂停 图标切换；重播或切换音乐时进度数字立即归零重置

### 资源占用优化

- 启动时只创建音频播放器、不预加载音源（修复后台持续占用 ~5% CPU 的问题）
- 单曲循环轮询计时器仅在单曲循环模式且正在播放时运行
- 进度时间标签最多每 500ms 更新一次
- 提醒轮询间隔 30 秒（每分钟至少检查一次，不影响提醒准确性）
- 实测空闲：CPU ≈ 0%，内存约 158MB（PySide6 基线，播放音乐时只增加音频解码开销）

### 便签

- 底部「便签」按钮打开便签窗口，输入自动保存（500ms 防抖），关闭时强制保存
- 便签窗口为俏皮绿色样式，文字 16px
- 便签改为即改即存（每次输入变化立即保存），无保存按键框；占位提示「记下一些小事…」完整显示

### 全局按钮排版

- 所有按钮加大加圆润（圆角 12px、内边距 8px+、15px 加粗），底部按钮带 emoji 图标（📷 🗓 ☑ 🎵 📝 ⚙）
- 迷你窗口顶部新增 🎵 音乐、📝 便签快捷按钮
- 迷你窗口头部布局：日期与星期独占一行、图标按钮独占一行，图标绝不遮挡日期文字
- 固定图标使用用户指定的 D:\Downloads 最新图片（无图时回退自绘图钉）
- 音乐 / 便签弹窗配色跟随当前主题（背景、按钮、边框、选中色均取自主题）
- 点「↗ 展开」恢复完整窗口（双击不再展开）
- 日期右侧、窗口顶部提供「…」固定按钮：点击后迷你窗口锁定当前位置不可拖动（按钮高亮），再点取消；固定状态会记住
- 迷你窗口不置顶、点击不激活不跳前（使用 Windows 不激活窗口属性，降低存在感）；被其他窗口盖住时保持在后面
- 迷你窗口出现时自动沉到其他窗口之后（lower），永不抢在最前；展开后恢复普通程序模式
- 展开后按正常程序设置：设置里开了「总在最前」则真正置顶（系统层强制生效），关闭则普通窗口
- 展开时正常激活显示：跳到最前并获得焦点
- 窗口内的「展开」「固定」按钮直接点击仍可用；「…」固定按钮只锁定拖动
- 不透明度可在设置中调节（30%-100%，默认 80%）
- 设置中可把「最小化按钮」改为收托盘、「关闭按钮」改为直接退出

### 完成确认与庆祝

- 勾选完成时弹出确认框（微软雅黑 13pt 加粗）：「你确定完成任务了吗( •̀ ω •́ )✧」
- 选项：「确定(●'◡'●)」和「我再想想¯\_(ツ)_/¯」；选「我再想想」则取消勾选、不标记完成
- 确认后播放音效并弹出庆祝提示「终于完成任务了耶o(*≧▽≦)ツ┏━┓！！！」（微软雅黑 13pt 加粗），文案可在设置中修改

### 设置按钮

- 设置窗口按钮：确认（应用并关闭）/ 应用（应用但不关闭，可连续调）/ 取消（不应用并关闭）

## 5. 提醒弹窗规范

- 位置：屏幕右下角
- 动画：从右下角滑入，约 300ms
- 停留：约 8 秒后自动消失，点击可立即关闭
- 内容：任务名称 + 提醒时间
- 样式：与主窗口同色系
- 多个提醒同时到点时，弹窗向上依次堆叠

### 时间选择器

- 添加 / 编辑计划中的开始、结束、提醒时间均使用大号时间按钮
- 点击后弹出「选择时间」窗口：左侧小时列表（00-23）、右侧分钟列表（00-59），可滚动快速选择
- 列表采用像素级平滑滚动，滚轮滚动更丝滑
- 滚动条为细圆胶囊样式（圆角滑块、无箭头按钮），与整体圆润风格一致
- 顶部大字号实时显示所选时间，双击列表项或点「确定」完成，另提供「现在」快捷键

### 开机自启动

- 设置中提供「开机自动启动」勾选项，默认关闭
- 通过当前用户注册表启动项实现，不影响其他用户

## 6. 交互反馈

- 新增、删除、置顶等操作有轻量动画或状态变化
- 删除前弹确认提示，防止误删
- 所有操作即时保存，重启软件不丢失

### 完成音效与动画

- 勾选完成：播放内置可爱短音效（约 0.16 秒，上行弹跳音，程序自绘无版权素材）
- 设置中提供「音效音频」：可选择本地音频（wav / mp3）、试听、恢复默认（默认使用 Music 音频的裁剪版 8月7日_裁剪.wav，已去掉开头静音）
- 设置中提供「音效音量」滑杆（0-100%），默认 12%；勾选完成与到点提醒共用
- 音效音量统一控制所有音效（勾选完成、到点提醒、按键提示音）
- 完成 / 取消完成切换：任务文字颜色渐变（约 260ms）+ 字体轻微弹跳（放大 6px 后回落），最后出现 / 移除划线
