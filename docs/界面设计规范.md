# 界面设计规范

> 版本：v0.1
> 说明：界面布局、配色、交互的统一标准，编写界面时遵循。

## 1. 设计原则

- 简洁、直观，日常查看不刺眼
- 背景透明，只显示内容区域
- 默认淡蓝色调，所有主要颜色可自定义

## 2. 主窗口布局

- 默认尺寸：约 820 x 540（横屏），可拖拽调整大小，最小 680 x 420
- 顶部：日期（左上角）+ 设置按钮
  - 点击日期会弹出日历，可快速跳转到任意日期（也保留前一天 / 今天 / 后一天按钮）
- 中部：搜索框；计划列表
  - 排序规则：置顶的计划在前；其余按时间段排序，无时间的按创建顺序
- 列表项：完成勾选 | 文字 + 时间段 | 置顶图标 | 编辑 | 删除
- 底部：添加计划按钮、今天按钮、前一天 / 后一天切换
- 独立图片区：课程表等图片缩略图，点击放大，可删除
- 每条计划可附带图片（选填）

## 3. 配色（默认淡蓝）

- 主色：#A8D8EA（淡蓝）
- 边框：#7FB8D4
- 按钮：#ADD8E6，悬停时加深
- 文字：#1F3A4D
- 完成态：#9AA5AC 划线显示
- 背景：透明（默认）
- 自定义范围：主色、边框、按钮、文字等主要颜色
  - 提供预设色板 + 自定义取色；可一键恢复默认淡蓝

### 任务字体颜色

- 每条任务可以选择字体颜色，按紧急程度区分：
  - 黑色（默认）、红色（紧急）、橙色（重要）、蓝色（常规）、绿色（轻松）、紫色（备忘）
- 已完成的任务统一显示为灰色并划线

## 4. 字体

- 微软雅黑；日期标题 18px，正文（任务内容）15px，时间 12px，按钮 14px

## 7. 桌面快捷方式

- 桌面上提供「每日计划」快捷方式图标（淡蓝色日历 + 对勾）
- 双击图标即可打开软件；图标可在 scripts/create_shortcut.ps1 中重新生成

## 8. 窗口置顶

- 窗口默认不置顶（普通窗口）；「总在最前」开关在后续版本提供，默认保持关闭

## 5. 提醒弹窗规范

- 位置：屏幕右下角
- 动画：从右下角滑入，约 300ms
- 停留：约 8 秒后自动消失，点击可立即关闭
- 内容：任务名称 + 提醒时间
- 样式：与主窗口同色系

## 6. 交互反馈

- 新增、删除、置顶等操作有轻量动画或状态变化
- 删除前弹确认提示，防止误删
- 所有操作即时保存，重启软件不丢失
