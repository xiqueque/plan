# 界面设计规范

> 版本：v0.1
> 说明：界面布局、配色、交互的统一标准，编写界面时遵循。

## 1. 设计原则

- 简洁、直观，日常查看不刺眼
- 背景透明，只显示内容区域
- 默认淡蓝色调，所有主要颜色可自定义

## 2. 主窗口布局

- 默认尺寸：约 820 x 540（横屏），可拖拽调整大小，最小 480 x 340
- 无边框透明圆角窗口：按住空白处可拖动位置，右下角拖拽柄可调整大小，左上角提供最小化（收托盘）与关闭（收托盘）按钮
- 顶部：日期（左上角）+ 设置按钮
  - 点击日期会弹出日历，可快速跳转到任意日期（也保留前一天 / 今天 / 后一天按钮）
- 中部：搜索框；计划列表
  - 排序规则：置顶的计划在前；其余按时间段排序，无时间的按创建顺序
- 列表项：完成勾选 | 文字 + 时间段 | 置顶 / 编辑 / 删除（大号按钮，15px 文字）
- 置顶的计划在任务文字右侧显示柔和淡蓝色自绘图钉小图标，一眼可辨且不刺眼
  - 完成勾选框为大号自绘圆角样式（36px），更醒目
  - 其他复选框（提醒日、时间段、开机自启等）勾选框统一放大为 22px，文字 15px
- 底部：添加计划、截图、设置按钮；顶部分别提供今天按钮、前一天 / 后一天切换
- 独立图片区：课程表等图片缩略图，点击放大，可删除
- 每条计划可附带图片（选填）

### 图片区与缩略图

- 搜索框下方为独立图片区：平时折叠为一行（「图片 ▸」+ 张数），点击展开；缩略图横向排列，可横向滚动
- 点击缩略图用电脑默认程序打开图片（设置中可选自定义程序，如画图）
- 右键缩略图弹出菜单：打开 / 重命名 / 标记为每日图片（或取消）/ 删除
- 标记为每日图片后，星标直接画在该缩略图左上角（金色 ★），不会出现第二张重复图片；右键可随时取消标记
- 每天提醒任务附带的图片自动每天出现在图片区（来源为任务，仅可打开/重命名，不可删除）
- 缩略图下方显示自定义名称（软件内右键重命名），过长自动省略
- 图片「重命名」是赋予新显示名（不改动原图片文件），支持中文、英文与 ASCII 字符；弹窗中有明确说明
- 设置窗口中的提示 / 注意文字使用淡灰色小字（12px），与主要选项区分开
- 图片复制到 app/data/images/ 保存，删除后文件一并清理；过期日期的图片随自动清理删除
- 添加 / 编辑计划时可附带图片（支持 png / jpg / jpeg / bmp / gif / webp），任务行显示「图片 N」标记

## 3. 配色（默认淡蓝）

- 主色：#A8D8EA（淡蓝）
- 边框：#7FB8D4
- 按钮：#ADD8E6，悬停时加深
- 文字：#1F3A4D
- 完成态：#9AA5AC 划线显示
- 背景：透明（默认）
- 自定义范围：主色、边框、按钮、文字等主要颜色
  - 提供预设色板 + 自定义取色；可一键恢复默认淡蓝

### 任务字体颜色

- 每条任务可以选择字体颜色，按紧急程度区分：
  - 黑色（默认）、红色（紧急）、橙色（重要）、蓝色（常规）、绿色（轻松）、紫色（备忘）
- 已完成的任务统一显示为灰色并划线

## 4. 字体

- 主字体：幼圆（圆润、可爱、饱满），后备微软雅黑
- 字号：日期标题 20px，任务正文 18px（字重 500），时间 13px，按钮 14px
- 任务文字加粗（字重 600）

## 6.2 计划截图卡片

- 点击「截图」生成当天的干净计划卡片（无软件按钮）
- 卡片样式：浅蓝背景 + 白色圆角任务行，与主界面一致
- 标题「每日计划 · 日期」；任务保留字体颜色；已完成任务灰色划线
- 文件名默认「每日计划_YYYY-MM-DD.png」

## 7. 桌面快捷方式

- 桌面上提供「每日计划」快捷方式图标（淡蓝色日历 + 对勾）
- 双击图标即可打开软件；图标可在 scripts/create_shortcut.ps1 中重新生成

## 8. 窗口置顶

- 窗口默认不置顶（普通窗口）；「总在最前」开关在后续版本提供，默认保持关闭

## 9. 主题与托盘

- 默认淡蓝主题；另提供 8 套图片配色主题（取自 C:\Users\Junhong\Pictures\peise 的 8 张样例图，程序自动提取主色）
- 8 套主题按配色分配四字名称（碧海晴空、青翠山林、暖阳橙光、桃粉春色、紫霞暮色、金秋麦浪、冰川银雪、莓果甜心）
- 主题在「设置 → 主题」中一键切换，界面背景、边框、按钮、文字随之变化
- 系统托盘：最小化 / 关闭收进托盘，提醒继续运行；托盘右键可显示或退出

### 迷你窗口

- 点击「—」默认进入桌面右上角半透明迷你窗口（默认约 320x240，最小 260x180，可拖动、右下角调整大小）
- 日期重点突出：月日 30px 加粗高亮，年份 + 星期 15px 加粗
- 任务双列显示，任务多时滚动条滚轮滑动
- 每个任务带勾选框，可在迷你窗口直接勾选完成（完成后灰色划线，播放音效）
- 任务有时间段时，在任务文字下方用淡灰色小字显示（如 09:00 – 10:00）
- 透明度只作用于背景：文字、数字与「展开」按钮始终清晰不透明（默认 80%）
- 双击窗口或点「↗ 展开」恢复完整窗口
- 不透明度可在设置中调节（30%-100%，默认 80%）
- 设置中可把「最小化按钮」改为收托盘、「关闭按钮」改为直接退出

## 5. 提醒弹窗规范

- 位置：屏幕右下角
- 动画：从右下角滑入，约 300ms
- 停留：约 8 秒后自动消失，点击可立即关闭
- 内容：任务名称 + 提醒时间
- 样式：与主窗口同色系
- 多个提醒同时到点时，弹窗向上依次堆叠

### 时间选择器

- 添加 / 编辑计划中的开始、结束、提醒时间均使用大号时间按钮
- 点击后弹出「选择时间」窗口：左侧小时列表（00-23）、右侧分钟列表（00-59），可滚动快速选择
- 列表采用像素级平滑滚动，滚轮滚动更丝滑
- 滚动条为细圆胶囊样式（圆角滑块、无箭头按钮），与整体圆润风格一致
- 顶部大字号实时显示所选时间，双击列表项或点「确定」完成，另提供「现在」快捷键

### 开机自启动

- 设置中提供「开机自动启动」勾选项，默认关闭
- 通过当前用户注册表启动项实现，不影响其他用户

## 6. 交互反馈

- 新增、删除、置顶等操作有轻量动画或状态变化
- 删除前弹确认提示，防止误删
- 所有操作即时保存，重启软件不丢失

### 完成音效与动画

- 勾选完成：播放内置可爱短音效（约 0.16 秒，上行弹跳音，程序自绘无版权素材）
- 设置中提供「音效音频」：可选择本地音频（wav / mp3）、试听、恢复默认（默认使用 Music 音频的裁剪版 8月7日_裁剪.wav，已去掉开头静音）
- 设置中提供「音效音量」滑杆（0-100%），默认 12%；勾选完成与到点提醒共用
- 完成 / 取消完成切换：任务文字颜色渐变（约 260ms）+ 字体轻微弹跳（放大 6px 后回落），最后出现 / 移除划线
