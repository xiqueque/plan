# 界面设计规范

> 版本：v0.1
> 说明：界面布局、配色、交互的统一标准，编写界面时遵循。

## 1. 设计原则

- 简洁、直观，日常查看不刺眼
- 背景透明，只显示内容区域
- 默认淡蓝色调，所有主要颜色可自定义

## 2. 主窗口布局

- 默认尺寸：约 380 x 660，可拖拽调整大小
- 顶部：日期（左上角）+ 设置按钮
- 中部：搜索框；计划列表
  - 排序规则：置顶的计划在前；其余按时间段排序，无时间的按创建顺序
- 列表项：完成勾选 | 文字 + 时间段 | 置顶图标 | 编辑 | 删除
- 底部：添加计划按钮、今天按钮、前一天 / 后一天切换
- 独立图片区：课程表等图片缩略图，点击放大，可删除
- 每条计划可附带图片（选填）

## 3. 配色（默认淡蓝）

- 主色：#A8D8EA（淡蓝）
- 边框：#7FB8D4
- 按钮：#ADD8E6，悬停时加深
- 文字：#1F3A4D
- 完成态：#9AA5AC 划线显示
- 背景：透明（默认）
- 自定义范围：主色、边框、按钮、文字等主要颜色
  - 提供预设色板 + 自定义取色；可一键恢复默认淡蓝

## 4. 字体

- 微软雅黑；标题 14-16px，正文 13px

## 5. 提醒弹窗规范

- 位置：屏幕右下角
- 动画：从右下角滑入，约 300ms
- 停留：约 8 秒后自动消失，点击可立即关闭
- 内容：任务名称 + 提醒时间
- 样式：与主窗口同色系

## 6. 交互反馈

- 新增、删除、置顶等操作有轻量动画或状态变化
- 删除前弹确认提示，防止误删
- 所有操作即时保存，重启软件不丢失
