# 技术方案

> 版本：v0.1
> 说明：本文件描述技术选型、模块划分与关键实现思路，编码前阅读。

## 1. 技术选型

- 语言与框架：Python 3 + PySide6（Qt 官方 Python 绑定）
  - 理由：原生支持透明无边框窗口、动画（提醒弹窗滑入）、系统托盘、本地音频播放；适合逐步迭代。
- 数据存储：JSON 本地文件，路径 `app/data/plan.json`
  - 存放每日计划、重复任务、图片记录、软件设置
- 图片管理：用户添加的图片复制到 `app/data/images/`，界面显示缩略图，点击查看原图
- 音频：默认内置一个可爱的短音效；设置中可替换为本地 mp3 / wav
- 打包：PyInstaller 打包成单个 .exe（如 `每日计划.exe`）
- 开机自启动：写入系统「启动」文件夹的快捷方式，设置中可开关

## 2. 目录结构（目标）

```
app/
├── main.py          # 程序入口
├── ui/              # 界面代码（主窗口、提醒弹窗、设置窗口）
├── core/            # 数据与逻辑（存储、提醒调度、设置）
├── assets/          # 内置音效、图标
└── data/            # 用户数据（运行后自动生成，不纳入版本管理）
```

## 3. 模块划分

- 存储模块：读写 JSON、图片管理、自动清理（超过 N 天，天数可调）
- 计划模块：新增 / 编辑 / 删除 / 置顶 / 搜索 / 勾选完成
  - 「每天提醒」任务单独存储定义，渲染到每一天的列表；完成状态按天记录
- 提醒模块：时间调度（QTimer），到点触发右下角弹窗 + 音效；软件未运行不补发
- 界面模块：
  - 主窗口：透明背景、日期显示、计划列表、搜索框、图片区、设置入口
  - 提醒弹窗：右下角滑入动画
  - 设置窗口：颜色、音效、开机自启、清理天数、总在最前
- 托盘模块：最小化到托盘、从托盘恢复

## 4. 关键技术点

- 透明无边框窗口：Qt `FramelessWindowHint` + `WA_TranslucentBackground`
- 提醒弹窗动画：`QPropertyAnimation` 从屏幕右下角滑入（约 300ms），停留数秒自动消失
- 每天提醒任务：重复任务定义与每日完成状态分离存储
- 自动清理：启动时检查并删除超过 N 天的非重复任务数据
- 本地音频播放：使用 Qt 多媒体或系统默认播放方式

## 5. 风险与对策

| 风险 | 对策 |
| --- | --- |
| 透明窗口在个别显卡 / 系统上显示异常 | 开发时在 Windows 10/11 上测试；提供「不透明背景」备选方案 |
| 打包体积较大 | 优先保证功能完整，后期再优化体积 |
| 中文显示乱码 | 统一 UTF-8 编码；界面字体使用系统「微软雅黑」 |
| 数据丢失 | 每次修改即时写盘；使用说明中写明备份 data 文件夹 |
| 时间 / 提醒误差 | 提醒调度用定时器按秒校验；打包后实测 |

## 6. 开发环境

- Windows 10/11 + Python 3.10+
- 依赖：PySide6、PyInstaller
- 代码用 git 管理，按阶段提交
