# 每日计划 使用说明

> 版本：1.0（2026-08-07 交付）
> 适用：Windows 电脑

## 1. 如何打开软件

- 双击桌面上的「每日计划」图标
- 或双击 `D:\project\plan\dist\每日计划.exe`
- 建议把桌面图标保持住，以后就从桌面打开
- 打包版第一次运行时，会自动在桌面创建「每日计划」快捷方式

## 2. 数据保存在哪里（重要）

- 打包版的数据保存在 **exe 同目录的 data 文件夹**里（`dist\data`）
- 里面包含：你的全部计划、图片、设置
- **备份方法**：把 `data` 文件夹复制一份存到别处即可
- **恢复方法**：把备份的 `data` 文件夹放回 exe 旁边（覆盖同名文件夹）
- 更新软件时复制新版 exe 替换旧版即可，`data` 文件夹原样保留，数据不丢

## 3. 日常使用

### 计划
- 「＋ 添加计划」新增；右侧「编辑 / 删除」修改；「置顶」把计划排到最前
- 勾选完成会弹出确认框（确定 / 我再想想），确认后有庆祝提示
- 每条计划可选时间段、字体颜色、每天重复
- 结束时间早于开始时间时视为跨午夜，列表中会显示淡灰色「次日」

### 提醒
- 编辑计划时可设置：提醒模式（不提醒 / 仅当日提醒 / 每天提醒）、提醒时间、提醒日（周一至周日任选）
- 到点后右下角弹出提醒小窗并播放音效
- 提醒只在软件运行时生效；建议在设置中开启「开机自动启动」

### 图片
- 主界面「图片」区：添加图片（课程表等）、点缩略图用系统默认程序打开
- 右键缩略图：打开 / 重命名 / 标记为每日图片（星标）/ 删除
- 编辑计划时可为每条计划附图片

### 截图
- 主界面「截图」：生成当天计划卡片图片
- 打开日历后「截图」：生成月度计划卡片图片

### 日历与月度计划
- 点左上角日期：大方块日历，方块内直接显示当天任务名，单击方块看详情，双击直接跳转
- 底部「月计划」：查看整月计划，可翻月

### 迷你窗口
- 点「—」缩小为桌面右上角的半透明迷你窗口（任务栏不显示、不置顶）
- 迷你窗口内点「↗ 展开」恢复完整窗口；「…」固定（锁定位置不可拖动）
- 行为可在设置中调整（缩小到托盘 / 直接退出）

### 主题
- 「设置 → 主题」可切换：默认淡蓝 + 8 套图片配色主题（碧海晴空、青翠山林等）
- 每次点击按钮都会播放提示音（程序自带昨天同款可爱音效 8月7日_裁剪.wav，默认音量 15%）

### 音乐播放器

- 底部「音乐」按钮：可播放 / 暂停 / 停止 / 上一首 / 下一首、添加本地音频、移除曲目、调节音量
- 默认已内置一首音乐（豪庭的音乐.mp3）；关闭播放器后音乐会继续播放，不想听点「停止」
- 播放模式支持：顺序播放 / 单曲循环 / 随机播放；随机模式下按钮显示「🔀 随机播放」
- 播放 / 暂停是一个按钮：按一下播放、再按一下暂停，图标随状态切换
- 双击曲目直接播放；直接拖拽曲目可调整播放顺序；添加新音乐后内置音乐保留

### 便签

- 底部「便签」按钮：随手记小事，输入后自动保存
- 配色图片随程序自带（exe 同目录的 peise 文件夹）；想自定义主题，把 peise 里的图片换成自己的即可（程序启动时自动提取配色）

## 4. 设置说明

- 完成音效：可选本地 wav / mp3，可试听、可恢复默认；音量可调
- 「音效音量」统一控制所有音效（勾选完成、提醒、按键提示音）
- 开机自动启动：到点提醒需要程序在运行，建议开启
- 自动清理天数：默认 0（不清除）；设为大于 0 的天数才会自动清理
- 窗口总在最前：默认关闭
- 迷你窗口不透明度、最小化/关闭按钮行为、完成任务后的提示语都可改

## 5. 常见问题

- **提醒不响**：检查程序是否在运行；建议开启开机自动启动
- **换了音效听不到**：先点「试听」确认；wav / mp3 均可
- **杀毒软件提示**：PyInstaller 打包的程序偶尔会被误报，添加信任即可
- **想恢复默认主题**：设置 → 主题 → 默认淡蓝
- **数据会不会丢**：只要不动 `data` 文件夹就不会丢；更新软件前建议备份一份
