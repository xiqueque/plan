# 每日计划 —— 项目工作区

这是一个运行在 Windows 桌面上的每日计划工具：透明背景、淡蓝色界面，支持每日计划编辑、搜索、置顶、删除、图片保存、到点提醒（右下角弹窗 + 可爱音效）、开机自启动。

## 目录结构

```
plan/
├── README.md              ← 本文件：项目总览与文件指引
├── docs/                  ← 项目文档（需求、技术、设计、步骤、规范）
│   ├── 需求规格说明书.md  ← 已确认的功能需求
│   ├── 技术方案.md        ← 技术选型与实现思路
│   ├── 界面设计规范.md    ← 界面布局 / 配色 / 交互标准
│   ├── 开发步骤.md        ← 分阶段开发计划
│   └── 开发规范.md        ← 日志 / git / 代码 / 测试 / 发布规则
├── logs/                  ← 每日开发日志（每天一个文件）
│   ├── 模板.md
│   └── 2026-08-07.md
├── app/                   ← 源代码（进入开发后生成）
└── .gitignore
```

## 文件指引

| docs/开发规范.md | 日志 / git / 测试 / 发布规则 | 每天开发时 |
| logs/ | 每日完成事项与待办事项 | 每天开发前、后 |

## 工作说明

1. 每个开发日：先查看 logs 中最新一天的日志和待办事项
2. 按 docs/开发步骤.md 的当前阶段执行开发
3. 每个开发日结束：更新当日日志（今日完成、待办事项、问题备注）
4. 需求调整：直接告知开发代理，并同步更新需求规格说明书
5. 所有改动通过 git 提交，按阶段记录，保证可回退
