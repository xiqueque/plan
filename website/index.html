📝 每日计划增删改、勾选完成、置顶、搜索、日历跳转、月度计划
⏰ 到点提醒右下角弹窗 + 可爱音效，周一至周日任选
🖼 图片课程表等图片随计划保存，每日图片星标
🎵 音乐播放器内置音乐，可加本地歌曲，随机/循环播放

🎨 8 套主题淡蓝默认，配色随图切换
🪟 迷你窗口桌面右上角半透明挂件，不打扰
📷 一键截图今日计划 / 月度计划卡片，发手机查看

🖥 系统要求

  • Windows 10 / 11
  • 无需安装其他软件，双击即可运行

📖 使用方法

  • 解压下载的压缩包（完整版），双击里面的 每日计划.exe
  • 首次运行会自动在桌面创建快捷方式
  • 你的数据保存在 exe 旁边的 data 文件夹，备份时复制它即可

❓ 常见问题

  • 杀毒软件提示？程序为独立打包，添加信任即可。
  • 提醒不响？请保持程序运行，或在设置中开启「开机自动启动」。
  • 想换音效？设置里可选择本地音频（wav / mp3）。
  • 更新软件？下载新版替换 exe，data 文件夹保留即可，数据不丢。
